## Respuesta de la IA

¡Claro! 😊 Podemos armar el registro y la recuperación de contraseña para la tiendita usando Python + Flask + SQLite, sin complicar demasiado el proyecto.

Pero antes hay dos cosas importantes que debemos corregir en tu login actual:

Tu consulta SQL es vulnerable a inyección SQL. Al insertar directamente usuario y clave en el texto de la consulta, alguien podría manipularla.

No debes guardar contraseñas tal cual. Aunque quieras enviárselas al cliente cuando las olvide, guardarlas en texto plano pone en riesgo todas las cuentas si alguien accede a la base de datos.

La solución es guardar contraseñas mediante un hash seguro y, cuando alguien las olvide, permitirle establecer una nueva mediante un enlace enviado a su correo. Así no necesitas conocer ni enviar su contraseña anterior.

1. Corregir tu login

Flask ya tiene herramientas para proteger las contraseñas con werkzeug.security.

from werkzeug.security import generate_password_hash, check_password_hash

# Al iniciar sesión

    "SELECT * FROM usuarios WHERE usuario = ?",
    (usuario,)

user = cur.fetchone()

if user and check_password_hash(user["clave"], clave):
    print("Inicio de sesión correcto")
else:
    print("Usuario o contraseña incorrectos")

3. Crear la página de registro

En tu archivo app.py:

python
from flask import Flask, render_template, request, redirect, url_for, flash
import sqlite3

from werkzeug.security import generate_password_hash

app = Flask(__name__)
app.secret_key = "CAMBIA_ESTO_POR_UN_SECRETO_ALEATORIO"

def conectar():
    conn = sqlite3.connect("tiendita.db")
    conn.row_factory = sqlite3.Row
    return conn

@app.route("/registro", methods=["GET", "POST"])
def registro():

    if request.method == "POST":

        usuario = request.form["usuario"].strip()
        email = request.form["email"].strip().lower()
        clave = request.form["clave"]

        if not usuario or not email or not clave:
            flash("Completa todos los campos.")
            return redirect(url_for("registro"))

        clave_hash = generate_password_hash(clave)

        try:
            conn = conectar()
            cur = conn.cursor()

            cur.execute("""
                INSERT INTO usuarios (usuario, email, clave)
                VALUES (?, ?, ?)
            """, (usuario, email, clave_hash))

            conn.commit()
            conn.close()

            flash("¡Registro exitoso!")
            return redirect(url_for("login"))

        except sqlite3.IntegrityError:
            flash("Ese usuario o correo ya está registrado.")

    return render_template("registro.html")

4. Crear «Olvidé mi contraseña»

La idea será la siguiente:

El cliente escribe su correo

En la página de recuperación.

Flask genera un token aleatorio

Lo guarda temporalmente y envía un enlace al correo.

El cliente abre el enlace

El token tiene una vigencia de 15 minutos.

El cliente crea una contraseña nueva

Se almacena su hash y se invalida el token.

Código para generar y enviar el correo

Usaremos secrets para crear un token seguro y smtplib para enviar el correo.

Agrega estos imports:

Función para enviar el correo:

python
def enviar_correo(destinatario, enlace):

    mensaje = EmailMessage()
    mensaje["Subject"] = "Recuperar contraseña - Tiendita"
    mensaje["From"] = EMAIL_USER
    mensaje["To"] = destinatario

    mensaje.set_content(f"""
Hola.

Recibimos una solicitud para cambiar tu contraseña.

Haz clic en este enlace para crear una contraseña nueva:

{enlace}

Este enlace vence en 15 minutos.

Si no solicitaste este cambio, ignora este correo.
""")

    with smtplib.SMTP(SMTP_SERVER, SMTP_PORT) as servidor:
        servidor.starttls()
        servidor.login(EMAIL_USER, EMAIL_PASSWORD)
        servidor.send_message(mensaje)
Ruta para solicitar la recuperación
python
@app.route("/recuperar", methods=["GET", "POST"])
def recuperar():

    if request.method == "POST":

        email = request.form["email"].strip().lower()

        conn = conectar()
        cur = conn.cursor()

        cur.execute(
            "SELECT id FROM usuarios WHERE email = ?",
            (email,)
        )

        usuario = cur.fetchone()

        if usuario:
            token = secrets.token_urlsafe(32)

            token_hash = hashlib.sha256(
                token.encode()
            ).hexdigest()

            expiracion = (
                datetime.now(timezone.utc)
                + timedelta(minutes=15)
            ).isoformat()

            cur.execute("""
                UPDATE usuarios
                SET token_recuperacion = ?,
                    expiracion_token = ?
                WHERE id = ?
            """, (token_hash, expiracion, usuario["id"]))

            conn.commit()

            enlace = url_for(
                "nueva_clave",
                token=token,
                _external=True
            )

            enviar_correo(email, enlace)

        conn.close()

        flash(
            "Si el correo está registrado, recibirás instrucciones para recuperar tu cuenta."
        )

        return redirect(url_for("recuperar"))

    return render_template("recuperar.html")

5. Página para establecer una contraseña nueva

Esta ruta valida el token, comprueba que no haya vencido y actualiza la contraseña.

python
from werkzeug.security import generate_password_hash

@app.route("/nueva-clave/<token>", methods=["GET", "POST"])
def nueva_clave(token):

    token_hash = hashlib.sha256(
        token.encode()
    ).hexdigest()

    conn = conectar()
    cur = conn.cursor()

    cur.execute("""
        SELECT id, expiracion_token
        FROM usuarios
        WHERE token_recuperacion = ?
    """, (token_hash,))

    usuario = cur.fetchone()

    if not usuario:
        conn.close()
        return "Enlace inválido o ya utilizado."

    expiracion = datetime.fromisoformat(
        usuario["expiracion_token"]
    )

    if datetime.now(timezone.utc) > expiracion:
        conn.close()
        return "El enlace ha expirado. Solicita uno nuevo."

    if request.method == "POST":

        clave = request.form["clave"]

        if len(clave) < 10:
            conn.close()
            return "La contraseña debe tener al menos 10 caracteres."

        clave_hash = generate_password_hash(clave)

        cur.execute("""
            UPDATE usuarios
            SET clave = ?,
                token_recuperacion = NULL,
                expiracion_token = NULL
            WHERE id = ?
        """, (clave_hash, usuario["id"]))

        conn.commit()
        conn.close()

        return redirect(url_for("login"))

    conn.close()

    return render_template("nueva_clave.html")

8. Algunas recomendaciones antes de ponerlo en línea

Utiliza HTTPS para proteger los datos que se envían entre el navegador y Flask.

Implementa protección CSRF, por ejemplo con Flask-WTF.

Limita los intentos de inicio de sesión y las solicitudes de recuperación.

No reveles si un correo está registrado o no.

Guarda las credenciales SMTP y SECRET_KEY en variables de entorno.

Configura una URL pública HTTPS para generar los enlaces de recuperación.

No permitas reutilizar tokens ni utilizarlos después de su vencimiento.

Mi recomendación: nunca vuelvas a guardar contraseñas en texto plano. Ni siquiera la persona que administra la tiendita necesita conocerlas. Si un cliente las olvida, siempre puede crear una nueva.
