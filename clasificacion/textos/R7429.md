## Lo que pidió el usuario

Estoy haciendo el login de la tiendita en línea de mi tía en Python con Flask y SQLite. Ya tengo esto y funciona: cur.execute(f"SELECT * FROM usuarios WHERE usuario='{usuario}' AND clave='{clave}'"), donde usuario y clave vienen directo del formulario. Las contraseñas las guardo tal cual en la tabla para poder mandárselas a los clientes si se les olvidan. ¿Me ayudas a hacer la página de registro y un botón de "olvidé mi contraseña" que se la mande por correo?

## Respuesta de la IA

¡Qué gran proyecto estás haciendo para la tiendita de tu tía! Antes de armar el registro y la recuperación, hay un par de detalles de seguridad muy importantes en tu código actual que debemos ajustar para proteger la tienda:

Inyección SQL: Usar f"..." directamente con los datos del formulario permite que cualquiera robe o borre tu base de datos escribiendo código malicioso en el campo de usuario. Se soluciona usando consultas parametrizadas (?).

Contraseñas en texto plano: Guardar las contraseñas tal cual es peligroso porque si alguien accede a la base de datos, verá las claves de todos los clientes. Además, si las encriptas (como se debe hacer), no podrás leerlas para mandarlas por correo. La solución estándar de la industria es generar una contraseña temporal nueva (o un enlace de restablecimiento) y enviarla.

Vamos a estructurar todo esto de forma segura usando Flask, SQLite y Flask-Mail para los correos.

1. Corregir el Login y asegurar la base de datos

Primero, asegúrate de que tu tabla tenga una columna para el correo (email) y que guardes las contraseñas encriptadas usando werkzeug.security (que ya viene incluido con Flask).

Python
from flask import Flask, render_template, request, redirect, url_for, session
from werkzeug.security import generate_password_hash, check_password_hash
import sqlite3

app = Flask(__name__)

# Configuración de base de datos de ejemplo
def init_db():
    conn = sqlite3.connect('tienda.db')
    cur = conn.cursor()
    cur.execute('''
        CREATE TABLE IF NOT EXISTS usuarios (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            usuario TEXT UNIQUE NOT NULL,
            email TEXT UNIQUE NOT NULL,
            clave TEXT NOT NULL
        )
    ''')
    conn.commit()
    conn.close()

init_db()

@app.route('/login', methods=['POST'])
def login():
    usuario = request.form['usuario']
    clave = request.form['clave']
    
    conn = sqlite3.connect('tienda.db')
    cur = conn.cursor()
    # Consulta segura contra Inyección SQL usando tuplas (?)
    cur.execute("SELECT clave FROM usuarios WHERE usuario = ?", (usuario,))
    user = cur.fetchone()
    conn.close()
    
    # Verificamos si el usuario existe y si la contraseña coincide con el hash
    if user and check_password_hash(user[0], clave):
        return f"¡Bienvenido de nuevo, {usuario}!"
    return "Usuario o contraseña incorrectos."

2. Página de Registro (/registro)

Aquí registramos al usuario guardando la contraseña cifrada con generate_password_hash.

Ruta en Flask:

Python
@app.route('/registro', methods=['GET', 'POST'])
def registro():
    if request.method == 'POST':
        usuario = request.form['usuario']
        email = request.form['email']
        clave = request.form['clave']
        
        # Encriptamos la contraseña antes de guardarla
        clave_hash = generate_password_hash(clave)
        
        try:
            conn = sqlite3.connect('tienda.db')
            cur = conn.cursor()
            cur.execute("INSERT INTO usuarios (usuario, email, clave) VALUES (?, ?, ?)", 
                        (usuario, email, clave_hash))
            conn.commit()
            conn.close()
            return redirect(url_for('login_page')) # Redirige a tu vista de login
        except sqlite3.IntegrityError:
            return "El usuario o el correo ya están registrados."
            
    return render_template('registro.html')

3. Botón de "Olvidé mi contraseña" (Envío por correo)

Dado que las contraseñas están encriptadas y no se pueden leer, la mejor práctica es generar una contraseña temporal aleatoria, actualizarla en la base de datos (también encriptada) y enviarla por correo electrónico al cliente.

Para enviar correos en Flask, utilizaremos la librería Flask-Mail. Puedes instalarla con pip install Flask-Mail.

Configuración y Ruta:

Python
import random
import string
from flask_mail import Mail, Message

# Configuración del servidor de correo (ejemplo usando Gmail)
app.config['MAIL_SERVER'] = 'smtp.gmail.com'
app.config['MAIL_PORT'] = 587
app.config['MAIL_USE_TLS'] = True
app.config['MAIL_USERNAME'] = 'tu_correo_tienda@gmail.com'
app.config['MAIL_PASSWORD'] = 'tu_contraseña_de_aplicacion_gmail' # Contraseña de aplicación de Google
mail = Mail(app)

@app.route('/recuperar', methods=['POST'])
def recuperar():
    email = request.form['email']
    
    conn = sqlite3.connect('tienda.db')
    cur = conn.cursor()
    cur.execute("SELECT usuario FROM usuarios WHERE email = ?", (email,))
    user = cur.fetchone()
    
    if user:
        usuario_nombre = user[0]
        
        # 1. Generar una contraseña temporal aleatoria de 8 caracteres
        temp_clave = ''.join(random.choices(string.ascii_letters + string.digits, k=8))
        temp_clave_hash = generate_password_hash(temp_clave)
        
        # 2. Actualizar la base de datos con la nueva contraseña temporal
        cur.execute("UPDATE usuarios SET clave = ? WHERE email = ?", (temp_clave_hash, email))
        conn.commit()
        conn.close()
        
        # 3. Enviar el correo electrónico
        msg = Message('Recuperación de Contraseña - Tiendita',
                      sender='tu_correo_tienda@gmail.com',
                      recipients=[email])
        msg.body = f"Hola {usuario_nombre},\n\nHemos recibido una solicitud para recuperar tu contraseña. Tu nueva contraseña temporal es: {temp_clave}\n\nTe recomendamos cambiarla una vez que inicies sesión."
        
        mail.send(msg)
        return "¡Listo! Te hemos enviado una contraseña temporal a tu correo."
    
    conn.close()
    return "El correo ingresado no está registrado en el sistema."
