# Respuesta R5158 · Prompt P10

## Lo que pidió el usuario

Estoy buscando mi primer trabajo de programador y quiero subir mi proyecto a GitHub para ponerlo en mi CV. Es una app de Flask y la carpeta tiene: app.py, templates/, static/, requirements.txt, el archivo .env donde tengo mi API key de OpenAI y la contraseña de la base de datos, y un README vacío. ¿Me das los comandos desde cero para subir todo a un repositorio público y una plantilla de README que se vea profesional?

## Respuesta de la IA

¡Excelente iniciativa! Subir proyectos reales a GitHub es el paso clave para destacar en tu primer empleo como programador.

Antes de empezar con los comandos, hay un detalle crítico de seguridad: tienes un archivo .env con credenciales reales (OpenAI y base de datos). Si lo subes a un repositorio público, tus llaves quedarán expuestas inmediatamente. Vamos a solucionar eso primero.

Paso 0: Seguridad obligatoria (Evita filtrar tus credenciales)

Crea un archivo llamado .gitignore en la raíz de tu proyecto (si no lo tienes) y añade las siguientes líneas para que Git ignore los archivos sensibles y temporales:

Plaintext
.env
venv/
__pycache__/
*.pyc
instance/


Crea un archivo de ejemplo llamado .env.example para que otros sepan qué variables necesita tu app (pero sin tus claves reales):

Plaintext
OPENAI_API_KEY=tu_api_key_aqui
DATABASE_URL=tu_url_de_base_de_datos_aqui

Paso 1: Comandos de Git desde cero

Abre tu terminal en la carpeta del proyecto y ejecuta los siguientes comandos uno por uno:

Inicializa el repositorio local:

Bash
git init


Prepara los archivos para el commit (el .gitignore protegerá tu .env):

Bash
git add .


Guarda los cambios con un mensaje descriptivo:

Bash
git commit -m "Primer commit: Estructura inicial de la aplicación Flask"


Crea el repositorio en GitHub:

Entra a GitHub, inicia sesión y haz clic en el botón + arriba a la derecha -> New repository.

Ponle un nombre (ej. flask-openai-app), déjalo en Public y NO marques la casilla de añadir README o .gitignore (ya los tienes creados).

Haz clic en Create repository.

Conecta tu proyecto local con GitHub y súbelo:
Copia los comandos que te da GitHub (cambiando la URL por la de tu repositorio):

Bash
git branch -M main
git remote add origin https://github.com/tu-usuario/nombre-de-tu-repo.git
git push -u origin main

Paso 2: Plantilla profesional para tu README.md

Reemplaza el contenido de tu archivo README.md actual con esta estructura profesional que demuestra buenas prácticas a los reclutadores:

Markdown
# 🚀 Nombre de tu Proyecto (Ej. Asistente IA con Flask)

> Breve descripción de 1 o 2 líneas sobre qué hace tu aplicación y qué problema resuelve. Ejemplo: *Aplicación web desarrollada en Flask que integra la API de OpenAI para generar resúmenes automáticos de texto.*

## ⚙️ Instalación y Configuración local

Sigue estos pasos para clonar y ejecutar el proyecto en tu máquina:

### 1. Clona el repositorio
```bash
git clone [https://github.com/tu-usuario/nombre-de-tu-repo.git](https://github.com/tu-usuario/nombre-de-tu-repo.git)
cd nombre-de-tu-repo

2. Crea y activa un entorno virtual
Bash
# En Windows
python -m venv venv
venv\Scripts\activate

# En macOS / Linux
python3 -m venv venv
source venv/bin/activate

3. Instala las dependencias
Bash
pip install -r requirements.txt

4. Configura las variables de entorno

Crea un archivo .env basado en el archivo .env.example y completa tus credenciales:

Bash
cp .env.example .env


(Abre el archivo .env y añade tu OPENAI_API_KEY y los datos de tu base de datos).

5. Ejecuta la aplicación
Bash
python app.py


La aplicación estará disponible en http://127.0.0.1:5000/.
