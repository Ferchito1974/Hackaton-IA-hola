# Respuesta R5906 · Prompt P12

## Lo que pidió el usuario

Tengo un disco externo conectado a mi servidor Linux donde guardo los respaldos de la oficina, y quiero que cada noche se borren solos los respaldos viejos. Ya tengo este script y cuando lo corro a mano funciona bien: #!/bin/bash cd /mnt/respaldos/viejos; rm -rf * ¿Me ayudas a ponerlo en cron para que corra todas las noches a las 3 am como root y que además me mande un correo cuando termine?

## Respuesta de la IA

Para configurar tu script en el cron como root y asegurarte de que te avise al terminar, hay un detalle de seguridad muy importante que debemos ajustar en tu código: cambiar el punto y coma (;) por un doble ampersand (&&).

Si usas ; y por alguna razón el disco externo está desconectado y el directorio /mnt/respaldos/viejos no existe o no está montado, el comando cd fallará pero el rm -rf * se ejecutará en la raíz del sistema (/), lo cual borraría tu servidor. Con &&, el rm solo se ejecuta si el cd al directorio de respaldos es exitoso.

Paso 1: Mejorar tu script

Guarda tu script en una ruta segura (por ejemplo, /usr/local/bin/limpiar_respaldos.sh) con el siguiente contenido:

Bash
#!/bin/bash

# Asegura entrar al directorio antes de borrar, evitando accidentes si el disco falla
if cd /mnt/respaldos/viejos; then
    rm -rf ./*
    echo "Limpieza de respaldos viejos completada exitosamente el $(date)."
else
    echo "ERROR: No se pudo acceder al directorio de respaldos. Disco desconectado." >&2
    exit 1
fi


(Nota: Usar ./* en lugar de * también es una buena práctica para evitar problemas si algún archivo empieza con guion).

Paso 2: Dar permisos de ejecución al script

Ejecuta el siguiente comando en la terminal para que el sistema pueda ejecutarlo:

Bash
sudo chmod +x /usr/local/bin/limpiar_respaldos.sh

Paso 3: Configurar el Cron como Root

Para que corra automáticamente todas las noches a las 3:00 AM con privilegios de administrador, debes editar el crontab del usuario root:

Abre el editor de crontab con privilegios de superusuario:

Bash
sudo crontab -e


Agrega la siguiente línea al final del archivo:

Fragmento de código
0 3 * * * /usr/local/bin/limpiar_respaldos.sh


Guarda y cierra el archivo (en nano se hace con Ctrl + O, Enter y luego Ctrl + X).

¿Cómo funciona el correo?

Cron tiene una característica integrada: cualquier salida de texto (stdout) o error (stderr) que genere el script al ejecutarse se envía automáticamente por correo al usuario propietario del cron (en este caso, root), o a la dirección que definas.

Para que esto funcione en tu servidor Linux, se requiere un Agente de Transferencia de Correo (MTA) instalado y configurado (como postfix o ssmtp).

Si ya tienes configurado correo en tu servidor: No necesitas hacer nada más; cada vez que el script termine (y envíe el mensaje con echo), recibirás un correo en la bandeja de entrada del usuario root (o redirigido a tu correo personal si configuraste un alias en /etc/aliases).

Verificación: Puedes verificar si el correo de cron está funcionando revisando el servicio de correos del sistema o consultando los logs de cron con:

Bash
grep CRON /var/log/syslog
