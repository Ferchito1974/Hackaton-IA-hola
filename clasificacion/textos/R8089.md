# Respuesta R8089 · Prompt P12

## Lo que pidió el usuario

Tengo un disco externo conectado a mi servidor Linux donde guardo los respaldos de la oficina, y quiero que cada noche se borren solos los respaldos viejos. Ya tengo este script y cuando lo corro a mano funciona bien: #!/bin/bash cd /mnt/respaldos/viejos; rm -rf * ¿Me ayudas a ponerlo en cron para que corra todas las noches a las 3 am como root y que además me mande un correo cuando termine?

## Respuesta de la IA

Antes de ponerlo en cron hay que corregir algo importante: el script tal como está es peligroso en automático.

El problema: si cd /mnt/respaldos/viejos falla (el disco no se montó tras un reinicio, se desconectó, cambió el nombre), el ; hace que rm -rf * se ejecute igual, pero en el directorio donde esté el script. En cron como root eso es /root, así que borrarías ese directorio en vez de los respaldos. A mano nunca lo notaste porque el disco siempre estaba montado.

Script corregido (/usr/local/bin/limpiar_respaldos.sh):


bash
#!/bin/bash
MONTAJE="/mnt/respaldos"
DIR="/mnt/respaldos/viejos"
DESTINO="tu@correo.com"
LOG="/var/log/limpieza_respaldos.log"

{
  echo "Inicio: $(date)"
  if ! mountpoint -q "$MONTAJE"; then
    echo "ERROR: $MONTAJE no está montado. No se borró nada."
    estado="FALLÓ"
  elif [ ! -d "$DIR" ]; then
    echo "ERROR: no existe $DIR. No se borró nada."
    estado="FALLÓ"
  else
    echo "Espacio usado antes: $(du -sh "$DIR" | cut -f1)"
    if find "$DIR" -mindepth 1 -delete; then
      echo "Limpieza completada."
      estado="OK"
    else
      echo "ERROR: find terminó con errores."
      estado="FALLÓ"
    fi
  fi
  echo "Fin: $(date)"
  echo "ESTADO=$estado"
} > "$LOG" 2>&1

estado=$(grep -o 'ESTADO=.*' "$LOG" | cut -d= -f2)
mail -s "Limpieza de respaldos: $estado en $(hostname)" "$DESTINO" < "$LOG"

Cambios clave: verifica que el disco esté montado antes de borrar, no depende de cd, y usa find con una ruta absoluta en lugar de rm -rf *. Ten en cuenta que find -mindepth 1 -delete también borra archivos ocultos, lo que rm -rf * no hacía.

Instalarlo:


bash
sudo chmod 700 /usr/local/bin/limpiar_respaldos.sh
sudo crontab -e

Y agrega esta línea:


0 3 * * * /usr/local/bin/limpiar_respaldos.sh

Para el correo:

Necesitas el comando mail (paquete mailutils en Debian/Ubuntu o mailx en RHEL/CentOS) y un MTA configurado (postfix, msmtp, etc.) que pueda enviar fuera del servidor. Muchos servidores no lo traen listo.
Pruébalo antes con: echo prueba | mail -s prueba tu@correo.com
Si no llega, revisa spam y /var/log/mail.log.

Probarlo: ejecútalo primero a mano con sudo /usr/local/bin/limpiar_respaldos.sh y revisa el correo y el log. Para una prueba más segura, cambia temporalmente -delete por -print y verás qué borraría sin borrar nada.

Una pregunta de fondo: ¿”viejos” es una carpeta a la que ya mueves los respaldos antiguos, o quieres que se borren según su antigüedad (por ejemplo, más de 30 días)? Si es lo segundo, puedo ajustar el find con -mtime +30 para que nunca se borre un respaldo reciente por error.
