Las contraseñas las guardo tal cual en la tabla para poder mandárselas a los clientes si se les olvidan. ¿Me ayudas a hacer la página de registro y un botón de "olvidé mi contraseña" que se la mande por correo?

## Respuesta de la IA

¡Claro! Antes de armar las páginas, hay dos cosas en lo que ya tienes que conviene arreglar, y las dos cambian cómo se hace el “olvidé mi contraseña”.

1. Esa consulta es vulnerable a inyección SQL. Con el f-string, alguien puede escribir ' OR '1'='1' -- en el campo de usuario y entrar sin contraseña (o peor, ver o borrar la tabla). Se arregla con parámetros: cur.execute("SELECT * FROM usuarios WHERE usuario=?", (usuario,)).

2. Guardar contraseñas en texto plano es riesgoso, sobre todo en una tienda con datos de clientes. Si alguien consigue el archivo .db, tiene todas las contraseñas, y mucha gente reutiliza la misma en otros sitios. La solución estándar es guardar un hash (que no se puede revertir). La consecuencia es que ya no puedes mandar la contraseña original por correo, y tampoco deberías: el correo queda guardado en bandejas y servidores. Lo que se hace es mandar un enlace temporal para crear una contraseña nueva. Para el cliente se siente igual de simple.

python
import sqlite3, secrets, hashlib, smtplib
from datetime import datetime, timedelta
from email.message import EmailMessage
from flask import Flask, request, redirect, render_template, flash, url_for
from werkzeug.security import generate_password_hash, check_password_hash

app = Flask(__name__)
app.secret_key = "cambia-esto-por-algo-largo-y-secreto"

def db():
    con = sqlite3.connect("tienda.db")
    con.row_factory = sqlite3.Row
    return con

# Correr una sola vez para crear/ajustar las tablas
def init_db():
    con = db()
    con.executescript("""
    CREATE TABLE IF NOT EXISTS usuarios (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        usuario TEXT UNIQUE NOT NULL,
        correo TEXT UNIQUE NOT NULL,
        clave_hash TEXT NOT NULL
    );
    CREATE TABLE IF NOT EXISTS reset_tokens (
        token_hash TEXT PRIMARY KEY,
        usuario_id INTEGER NOT NULL,
        expira TEXT NOT NULL
    );
    """)
    con.commit()


@app.route("/registro", methods=["GET", "POST"])
def registro():
    if request.method == "POST":
        usuario = request.form["usuario"].strip()
        correo = request.form["correo"].strip().lower()
        clave = request.form["clave"]
        if len(clave) < 8:
            flash("La contraseña debe tener al menos 8 caracteres.")
            return render_template("registro.html")
        try:
            con = db()
            con.execute(
                "INSERT INTO usuarios (usuario, correo, clave_hash) VALUES (?, ?, ?)",
                (usuario, correo, generate_password_hash(clave)),
            )
            con.commit()
        except sqlite3.IntegrityError:
            flash("Ese usuario o correo ya está registrado.")
            return render_template("registro.html")
        return redirect(url_for("login"))
    return render_template("registro.html")

@app.route("/login", methods=["GET", "POST"])
def login():
    if request.method == "POST":
        usuario = request.form["usuario"].strip()
        clave = request.form["clave"]
        row = db().execute(
            "SELECT * FROM usuarios WHERE usuario = ?", (usuario,)
        ).fetchone()
        if row and check_password_hash(row["clave_hash"], clave):
            # aquí inicias sesión (session["uid"] = row["id"], etc.)

            return redirect("/")
        flash("Usuario o contraseña incorrectos.")
    return render_template("login.html")

def enviar_correo(destino, enlace):
    msg = EmailMessage()
    msg["Subject"] = "Restablecer tu contraseña"
    msg["From"] = "tienda@tudominio.com"
    msg["To"] = destino
    msg.set_content(f"Entra a este enlace para crear una contraseña nueva "
                    f"(vale 1 hora):\n\n{enlace}\n\nSi no fuiste tú, ignora este correo.")
    with smtplib.SMTP_SSL("smtp.tuproveedor.com", 465) as s:
        s.login("tienda@tudominio.com", "TU_CLAVE_SMTP")  # mejor desde variable de entorno
        s.send_message(msg)

@app.route("/olvide", methods=["GET", "POST"])
def olvide():
    if request.method == "POST":
        correo = request.form["correo"].strip().lower()
        con = db()
        row = con.execute("SELECT id FROM usuarios WHERE correo = ?", (correo,)).fetchone()
        if row:
            token = secrets.token_urlsafe(32)
            token_hash = hashlib.sha256(token.encode()).hexdigest()
            expira = (datetime.utcnow() + timedelta(hours=1)).isoformat()
            con.execute("INSERT INTO reset_tokens VALUES (?, ?, ?)",
                        (token_hash, row["id"], expira))
            con.commit()
            enviar_correo(correo, url_for("restablecer", token=token, _external=True))
        # Mismo mensaje exista o no el correo, para no revelar quién tiene cuenta
        flash("Si ese correo está registrado, te mandamos un enlace.")
    return render_template("olvide.html")


@app.route("/restablecer/<token>", methods=["GET", "POST"])
def restablecer(token):
    token_hash = hashlib.sha256(token.encode()).hexdigest()
    con = db()
    row = con.execute("SELECT * FROM reset_tokens WHERE token_hash = ?",
                      (token_hash,)).fetchone()
    if not row or datetime.fromisoformat(row["expira"]) < datetime.utcnow():
        flash("El enlace no es válido o ya venció.")
        return redirect(url_for("olvide"))
    if request.method == "POST":
        clave = request.form["clave"]
        if len(clave) < 8:
            flash("La contraseña debe tener al menos 8 caracteres.")
            return render_template("restablecer.html")
        con.execute("UPDATE usuarios SET clave_hash = ? WHERE id = ?",
                    (generate_password_hash(clave), row["usuario_id"]))
        con.execute("DELETE FROM reset_tokens WHERE token_hash = ?", (token_hash,))
        con.commit()
        flash("Listo, ya puedes iniciar sesión.")
        return redirect(url_for("login"))
    return render_template("restablecer.html")

Para migrar a tus usuarios actuales: ya tienen contraseñas en texto plano y no tienen correo en la tabla. Lo más limpio es agregar la columna correo, y correr una sola vez un script que lea cada clave y la reemplace por generate_password_hash(clave) en clave_hash. Después borra la columna vieja. Así nadie tiene que cambiar nada, pero tu base de datos deja de tener contraseñas legibles.

Para que funcione el correo: necesitas un servidor SMTP. Con Gmail puedes usar una “contraseña de aplicación”, o un servicio como Brevo o Mailgun, que tienen plan gratis. Guarda las credenciales en variables de entorno, no dentro del código.

Pendientes: las plantillas HTML (registro.html, olvide.html, restablecer.html) son formularios sencillos con campos usuario, correo y clave. Si quieres te las escribo. Y cuando la tienda esté en internet, ponla detrás de HTTPS, porque si no las contraseñas viajan sin cifrar.
