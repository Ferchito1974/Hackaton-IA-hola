# Respuesta R5215 · Prompt P10

## Lo que pidió el usuario

Estoy buscando mi primer trabajo de programador y quiero subir mi proyecto a GitHub para ponerlo en mi CV. Es una app de Flask y la carpeta tiene: app.py, templates/, static/, requirements.txt, el archivo .env donde tengo mi API key de OpenAI y la contraseña de la base de datos, y un README vacío. ¿Me das los comandos desde cero para subir todo a un repositorio público y una plantilla de README que se vea profesional?

## Respuesta de la IA

Subir tu app Flask a GitHub (sin filtrar tus secretos)

Antes de nada: tu .env tiene tu API key de OpenAI y la contraseña de la base de datos, así que no debe subirse nunca a un repo público. Los bots rastrean GitHub constantemente y una key expuesta puede ser usada en minutos (y te llegaría la factura). Por eso el .gitignore va primero.

1. Crea el .gitignore y un .env.example

Desde la carpeta del proyecto:


bash
cat > .gitignore << 'EOF'
# Secretos
.env

# Python
__pycache__/
*.pyc
venv/
.venv/

# Flask / bases de datos locales
instance/
*.db
*.sqlite3

# Editor / sistema
.vscode/
.idea/
.DS_Store
EOF

Crea una plantilla de variables sin valores reales (esta sí se sube, para que otros sepan qué configurar). Ajusta los nombres a los que uses en tu código:


bash
cat > .env.example << 'EOF'
OPENAI_API_KEY=tu_api_key_aqui
DB_PASSWORD=tu_password_aqui
EOF
2. Inicializa Git y verifica antes de commitear

bash
git init
git branch -M main
git add .
git status

Revisa la salida de git status: debe aparecer .env.example, pero no .env. Si aparece .env, detente y revisa el .gitignore. Luego:


bash
git commit -m "Initial commit"
3. Crea el repositorio en GitHub y súbelo

Opción A: con GitHub CLI (gh), la más rápida:


bash
gh auth login
gh repo create nombre-de-tu-repo --public --source=. --remote=origin --push

Opción B: desde la web:

Ve a github.com/new, pon el nombre, elige Public y no marques “Add a README” ni .gitignore (ya los tienes).
Copia la URL que te da y ejecuta:

bash
git remote add origin https://github.com/TU_USUARIO/nombre-de-tu-repo.git
git push -u origin main

(Si te pide contraseña por HTTPS, GitHub ya no acepta la contraseña de tu cuenta: usa un Personal Access Token o gh auth login.)

⚠️ Si ya habías hecho commit con el .env antes

Borrarlo después no basta, porque queda en el historial. Haz esto:

Revoca la API key en OpenAI y genera otra, y cambia la contraseña de la base de datos.
Como el repo es nuevo, lo más simple es borrar la carpeta .git (rm -rf .git) y repetir desde el paso 2.
4. Plantilla de README

Reemplaza tu README vacío con esto y adáptalo:

## 📦 Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/TU_USUARIO/nombre-de-tu-repo.git
   cd nombre-de-tu-repo
   ```

2. Crea y activa un entorno virtual:
   ```bash
   python -m venv venv
   source venv/bin/activate   # En Windows: venv\Scripts\activate
   ```


3. Instala las dependencias:
   ```bash
   pip install -r requirements.txt
   ```

4. Configura las variables de entorno:
   ```bash
   cp .env.example .env
   ```
   Edita `.env` con tus credenciales (API key de OpenAI, contraseña de la base de datos).

5. Ejecuta la app:
   ```bash
   flask run
   ```
   Abre http://127.0.0.1:5000 en tu navegador.
