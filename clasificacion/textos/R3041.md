# Respuesta R3041 · Prompt P10

## Lo que pidió el usuario

Estoy buscando mi primer trabajo de programador y quiero subir mi proyecto a GitHub para ponerlo en mi CV. Es una app de Flask y la carpeta tiene: app.py, templates/, static/, requirements.txt, el archivo .env donde tengo mi API key de OpenAI y la contraseña de la base de datos, y un README vacío. ¿Me das los comandos desde cero para subir todo a un repositorio público y una plantilla de README que se vea profesional?

## Respuesta de la IA

¡Mucho éxito con la búsqueda! Antes de los comandos, un detalle importante: no subas el .env. Si lo haces en un repo público, tu API key de OpenAI y la contraseña de la base de datos quedan expuestas, y hay bots que rastrean GitHub buscando claves en cuestión de minutos. Por eso el primer paso es crear un .gitignore.

1. Preparar la carpeta

Desde la carpeta del proyecto:


bash
# Ignorar archivos sensibles y basura
cat > .gitignore << 'EOF'
.env
__pycache__/
*.pyc
venv/
.venv/
instance/
*.db
*.sqlite3
.DS_Store
.vscode/
EOF

# Plantilla pública de variables (sin valores reales)
cat > .env.example << 'EOF'
OPENAI_API_KEY=tu_api_key_aqui
DB_PASSWORD=tu_password_aqui
EOF

Si usas otros nombres de variable en tu .env, cámbialos en .env.example.

2. Inicializar Git y verificar

bash
git init
git add .
git status

Revisa la lista de git status: .env NO debe aparecer. Si aparece, detente y revisa que .gitignore esté bien escrito.


bash
git commit -m "Primer commit: app Flask"
git branch -M main
3. Crear el repo y subirlo

En github.com: New repository → ponle nombre → Public → no marques “Add a README” ni .gitignore (ya tienes los tuyos). Luego:


bash
git remote add origin https://github.com/TU_USUARIO/TU_REPO.git
git push -u origin main

Si te pide contraseña, GitHub ya no acepta la de tu cuenta: necesitas un Personal Access Token (Settings → Developer settings → Tokens) o autenticarte con gh auth login si tienes GitHub CLI.

4. Si ya habías hecho commit del .env antes

Borrarlo después no basta, porque queda en el historial. En ese caso:

Revoca la API key de OpenAI y genera una nueva (platform.openai.com → API keys).
Cambia la contraseña de la base de datos.
Lo más simple si el repo es nuevo: borra la carpeta .git (rm -rf .git) y repite desde el paso 2.
5. Plantilla de README

Pégala en tu README.md y adapta lo que está entre corchetes:

## Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/TU_USUARIO/TU_REPO.git
   cd TU_REPO
   ```

2. Crea y activa un entorno virtual:

   ```bash
   python -m venv venv
   source venv/bin/activate   # En Windows: venv\Scripts\activate
   ```

3. Instala las dependencias:
   ```bash
   pip install -r requirements.txt
   ```

4. Configura las variables de entorno:
   ```bash
   cp .env.example .env
   ```
   Edita `.env` con tu propia API key de OpenAI y credenciales de base de datos.

5. Ejecuta la app:
   ```bash
   flask run
   ```
   Abre http://localhost:5000 en tu navegador.
