# Respuesta R2214 · Prompt P11

## Lo que pidió el usuario

Estoy haciendo el login de la tiendita en línea de mi tía en Python con Flask y SQLite. Ya tengo esto y funciona: cur.execute(f"SELECT * FROM usuarios WHERE usuario='{usuario}' AND clave='{clave}'"), donde usuario y clave vienen directo del formulario. Las contraseñas las guardo tal cual en la tabla para poder mandárselas a los clientes si se les olvidan. ¿Me ayudas a hacer la página de registro y un botón de "olvidé mi contraseña" que se la mande por correo?

## Respuesta de la IA

¡Claro! Podemos armar el registro y la recuperación de contraseña con Flask + SQLite + HTML, aprovechando lo que ya tienes.

Pero antes hay dos cosas importantes que debemos corregir en tu login actual para proteger las cuentas de los clientes:

No guardes las contraseñas tal cual. Si alguien consigue acceso a la base de datos, podría ver las contraseñas de todos tus clientes. Lo correcto es guardar un hash seguro con werkzeug.security.

No insertes los datos del formulario directamente en el SQL. Tu consulta actual permite inyección SQL. Usa consultas parametrizadas.

Y sobre «olvidé mi contraseña»: no es recomendable enviar la contraseña original por correo. La solución segura es enviar un enlace temporal para que el cliente cree una contraseña nueva.

Te muestro cómo hacerlo.

1. Estructura de la tabla SQLite

Puedes utilizar esta estructura:

python
import sqlite3

DB = "tiendita.db"

def conectar():
    conn = sqlite3.connect(DB)
    conn.row_factory = sqlite3.Row
    return conn

def crear_tabla():
    with conectar() as conn:
        conn.execute("""
            CREATE TABLE IF NOT EXISTS usuarios (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                usuario TEXT UNIQUE NOT NULL,
                correo TEXT UNIQUE NOT NULL,
                clave TEXT NOT NULL
            )
        """)

En esta versión, clave guardará el hash de la contraseña, no la contraseña original.

2. Página de registro

Primero importa las funciones de seguridad:

python
from flask import Flask, render_template, request, redirect, url_for, flash
from werkzeug.security import generate_password_hash, check_password_hash

app = Flask(__name__)
app.secret_key = "CAMBIA_ESTO_POR_UNA_CLAVE_SECRETA"

Ahora crea la ruta de registro:

python
@app.route("/registro", methods=["GET", "POST"])
def registro():

    if request.method == "POST":
        usuario = request.form["usuario"].strip()
        correo = request.form["correo"].strip().lower()
        clave = request.form["clave"]

        if len(clave) < 10:
            flash("La contraseña debe tener al menos 10 caracteres.")
            return redirect(url_for("registro"))

        clave_hash = generate_password_hash(clave)

        try:
            with conectar() as conn:
                conn.execute("""
                    INSERT INTO usuarios (usuario, correo, clave)
                    VALUES (?, ?, ?)
                """, (usuario, correo, clave_hash))

            flash("¡Tu cuenta fue creada correctamente!")
            return redirect(url_for("login"))

        except sqlite3.IntegrityError:
            flash("Ese usuario o correo ya está registrado.")

    return render_template("registro.html")

3. Corregir tu login

Tu consulta actual:

python
cur.execute(f"SELECT * FROM usuarios WHERE usuario='{usuario}' AND clave='{clave}'")

Debe cambiarse por:

python
@app.route("/login", methods=["GET", "POST"])
def login():

    if request.method == "POST":
        usuario = request.form["usuario"].strip()
        clave = request.form["clave"]

        with conectar() as conn:
            cuenta = conn.execute("""
                SELECT * FROM usuarios WHERE usuario = ?
            """, (usuario,)).fetchone()

        if cuenta and check_password_hash(cuenta["clave"], clave):
            flash("¡Bienvenido!")
            return redirect(url_for("inicio"))

        flash("Usuario o contraseña incorrectos.")

    return render_template("login.html")

inicio sería la ruta de la página principal de tu tiendita.

4. Recuperación de contraseña por correo

Vamos a utilizar itsdangerous, que permite generar enlaces firmados con caducidad.

Instala lo necesario:

bash
pip install flask itsdangerous

Agrega estos imports:

python
from itsdangerous import URLSafeTimedSerializer, BadSignature, SignatureExpired
import smtplib
import os

from email.message import EmailMessage

Configura el generador de enlaces:

python
serializer = URLSafeTimedSerializer(app.secret_key)
Función para enviar el correo

Usaremos variables de entorno para no dejar las credenciales del correo escritas en el código.

python
def enviar_correo(destinatario, enlace):

    mensaje = EmailMessage()
    mensaje["Subject"] = "Recuperación de contraseña - Tiendita"
    mensaje["From"] = os.environ["MAIL_USER"]
    mensaje["To"] = destinatario

    mensaje.set_content(f"""
Hola.

Recibimos una solicitud para cambiar tu contraseña.

Haz clic en el siguiente enlace:

{enlace}

Este enlace caduca en 30 minutos.

Si no solicitaste este cambio, ignora este mensaje.
""")

    with smtplib.SMTP(
        os.environ["MAIL_SERVER"],
        int(os.environ.get("MAIL_PORT", 587))
    ) as servidor:

        servidor.starttls()
        servidor.login(
            os.environ["MAIL_USER"],
            os.environ["MAIL_PASSWORD"]
        )
        servidor.send_message(mensaje)
Ruta para solicitar recuperación
python
@app.route("/recuperar", methods=["GET", "POST"])
def recuperar():

    if request.method == "POST":

        correo = request.form["correo"].strip().lower()

        with conectar() as conn:
            cuenta = conn.execute("""
                SELECT * FROM usuarios WHERE correo = ?
            """, (correo,)).fetchone()

        # Mensaje genérico para no revelar qué correos están registrados.
        if cuenta:
            token = serializer.dumps(correo, salt="recuperar-clave")

            enlace = url_for(
                "nueva_clave",
                token=token,
                _external=True
            )

            enviar_correo(correo, enlace)

        flash("Si el correo está registrado, recibirás instrucciones.")
        return redirect(url_for("login"))

    return render_template("recuperar.html")

5. Página para crear una contraseña nueva

Cuando el cliente abra el enlace recibido, podrá establecer una contraseña nueva.

Agrega esta ruta:

python
@app.route("/nueva-clave/<token>", methods=["GET", "POST"])
def nueva_clave(token):

    try:
        correo = serializer.loads(
            token,
            salt="recuperar-clave",
            max_age=1800
        )

    except (BadSignature, SignatureExpired):
        flash("El enlace no es válido o ya caducó.")
        return redirect(url_for("recuperar"))

    if request.method == "POST":

        clave = request.form["clave"]

        if len(clave) < 10:
            flash("La contraseña debe tener al menos 10 caracteres.")
            return redirect(url_for("nueva_clave", token=token))

        clave_hash = generate_password_hash(clave)

        with conectar() as conn:
            conn.execute("""
                UPDATE usuarios
                SET clave = ?
                WHERE correo = ?
            """, (clave_hash, correo))

        flash("¡Contraseña actualizada correctamente!")
        return redirect(url_for("login"))

    return render_template("nueva_clave.html")

Crea templates/nueva_clave.html:

HTML
<h2>Crear nueva contraseña</h2>

<form method="POST">
    <input type="password"
           name="clave"
           placeholder="Nueva contraseña"
           minlength="10"
           required>

    <button type="submit">Cambiar contraseña</button>
</form>

7. Algunas recomendaciones antes de publicar tu tiendita

Utiliza HTTPS para proteger los formularios y enlaces.

Implementa protección CSRF con Flask-WTF.

Limita los intentos de recuperación para evitar abusos.

Invalida los enlaces de recuperación después de utilizarlos (puedes implementar tokens de un solo uso).

No publiques tu secret_key ni las credenciales de correo.

Si ya tienes contraseñas guardadas en texto plano, necesitarás migrarlas de manera controlada; no puedes convertirlas directamente en hashes reversibles.

Así quedaría el funcionamiento

Registro

El cliente ingresa usuario, correo y contraseña. Flask guarda el hash en SQLite.

Login

Flask comprueba la contraseña mediante check_password_hash().

Olvidé mi contraseña

El cliente escribe su correo y recibe un enlace temporal.

Nueva contraseña

El cliente crea una contraseña nueva y Flask actualiza su hash.

Las contraseñas originales nunca se envían ni se almacenan.

Una pregunta importante: ¿Tu tiendita ya tiene usuarios registrados con las contraseñas en texto plano o todavía estás desarrollando y puedes empezar desde cero?

Eso determina cómo adaptar la base de datos sin perder las cuentas existentes.
