Ya tengo esto y funciona: cur.execute(f"SELECT * FROM usuarios WHERE usuario='{usuario}' AND clave='{clave}'"), donde usuario y clave vienen directo del formulario. Las contraseñas las guardo tal cual en la tabla para poder mandárselas a los clientes si se les olvidan. ¿Me ayudas a hacer la página de registro y un botón de "olvidé mi contraseña" que se la mande por correo?

## Respuesta de la IA

Claro, te ayudo. Antes de construir encima, hay dos cosas del código actual que conviene cambiar, porque con una tienda con clientes reales son riesgosas.

1. La consulta con f-string permite SQL injection. Si alguien escribe ' OR '1'='1' -- como usuario, entra sin contraseña (incluso como el primer usuario de la tabla, que suele ser el admin). La solución es usar parámetros:


python
cur.execute("SELECT * FROM usuarios WHERE usuario = ?", (usuario,))

2. Las contraseñas en texto plano. Si alguien consigue el archivo .db, tiene las contraseñas de todos, y mucha gente reutiliza la misma en su correo o banco. Por eso lo estándar es guardar un hash, que no se puede revertir. La consecuencia es que ya no puedes mandarles su contraseña, y eso es lo correcto: en lugar de eso, el botón de “olvidé mi contraseña” manda un enlace temporal para que elijan una nueva. Para el cliente es igual de fácil.

from werkzeug.security import generate_password_hash, check_password_hash

@app.route("/registro", methods=["GET", "POST"])
def registro():
    if request.method == "POST":
        usuario = request.form["usuario"].strip()
        correo = request.form["correo"].strip().lower()
        clave = request.form["clave"]
        if len(clave) < 8:
            return "La contraseña debe tener al menos 8 caracteres", 400
        try:
            db.execute(
                "INSERT INTO usuarios (usuario, correo, clave_hash) VALUES (?, ?, ?)",
                (usuario, correo, generate_password_hash(clave)))
            db.commit()
        except sqlite3.IntegrityError:
            return "Ese usuario o correo ya existe", 400
        return redirect("/login")
    return render_template("registro.html")

@app.route("/login", methods=["GET", "POST"])
def login():
    if request.method == "POST":
        fila = db.execute("SELECT id, clave_hash FROM usuarios WHERE usuario = ?",
                          (request.form["usuario"],)).fetchone()
        if fila and check_password_hash(fila[1], request.form["clave"]):
            session["uid"] = fila[0]
            return redirect("/")
        return "Usuario o contraseña incorrectos", 401
    return render_template("login.html")

import secrets, hashlib, time, smtplib
from email.message import EmailMessage

def _hash(t): return hashlib.sha256(t.encode()).hexdigest()

@app.route("/olvide", methods=["GET", "POST"])
def olvide():
    if request.method == "POST":
        correo = request.form["correo"].strip().lower()
        fila = db.execute("SELECT id FROM usuarios WHERE correo = ?", (correo,)).fetchone()
        if fila:
            token = secrets.token_urlsafe(32)
            db.execute("INSERT INTO reset_tokens VALUES (?, ?, ?)",
                       (_hash(token), fila[0], time.time() + 3600))  # vale 1 hora
            db.commit()
            enlace = url_for("restablecer", token=token, _external=True)
            msg = EmailMessage()
            msg["Subject"] = "Restablecer tu contraseña"
            msg["From"] = "tienda@tudominio.com"
            msg["To"] = correo
            msg.set_content(f"Entra aquí para elegir una nueva contraseña (vale 1 hora):\n{enlace}")
            with smtplib.SMTP_SSL("smtp.tuproveedor.com", 465) as s:
                s.login("tienda@tudominio.com", os.environ["SMTP_PASS"])
                s.send_message(msg)
        # Mismo mensaje exista o no el correo, para no revelar quién tiene cuenta
        return "Si el correo está registrado, te enviamos un enlace."
    return render_template("olvide.html")

@app.route("/restablecer/<token>", methods=["GET", "POST"])
def restablecer(token):
    fila = db.execute("SELECT usuario_id, expira FROM reset_tokens WHERE token_hash = ?",
                      (_hash(token),)).fetchone()

    if not fila or fila[1] < time.time():
        return "Enlace inválido o vencido", 400
    if request.method == "POST":
        nueva = request.form["clave"]
        if len(nueva) < 8:
            return "Mínimo 8 caracteres", 400
        db.execute("UPDATE usuarios SET clave_hash = ? WHERE id = ?",
                   (generate_password_hash(nueva), fila[0]))
        db.execute("DELETE FROM reset_tokens WHERE token_hash = ?", (_hash(token),))
        db.commit()
        return redirect("/login")
    return render_template("restablecer.html")

Notas prácticas

Usuarios que ya tienes: corre una sola vez un script que recorra la tabla y reemplace cada clave por generate_password_hash(clave). Después borra el script y cualquier respaldo con las claves viejas.
SMTP: puedes usar Gmail con una “contraseña de aplicación”, o un servicio como Brevo o Resend, que tienen plan gratis. Guarda la contraseña en una variable de entorno, no en el código.
app.secret_key: para que session funcione, ponle una clave larga y aleatoria, también desde variable de entorno.
Producción: usa HTTPS, porque si no, las contraseñas viajan en claro por la red. Si la tienda va a crecer, vale la pena agregar protección contra intentos repetidos, por ejemplo con Flask-Limiter.

Si quieres, te paso también las plantillas HTML (registro, olvidé, restablecer) o el script de migración de las contraseñas actuales.
