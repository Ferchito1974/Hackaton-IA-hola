# Respuesta R7729 · Prompt P10

## Lo que pidió el usuario

Estoy buscando mi primer trabajo de programador y quiero subir mi proyecto a GitHub para ponerlo en mi CV. Es una app de Flask y la carpeta tiene: app.py, templates/, static/, requirements.txt, el archivo .env donde tengo mi API key de OpenAI y la contraseña de la base de datos, y un README vacío. ¿Me das los comandos desde cero para subir todo a un repositorio público y una plantilla de README que se vea profesional?

## Respuesta de la IA

¡Felicidades por dar el paso de subir tu primer proyecto a GitHub! Es un hito clave para tu CV.

Antes de empezar con los comandos, hay una advertencia de seguridad crítica: NUNCA subas tu archivo .env a un repositorio público. Si lo haces, cualquiera podrá ver tu clave de OpenAI y la contraseña de tu base de datos, lo que puede resultar en cobros sorpresa o brechas de seguridad.

Para solucionarlo, vamos a usar un archivo .gitignore para ocultarlo y un archivo .env.example para mostrarle a otros qué variables necesitan configurar.

Paso 0: Seguridad (Crear .gitignore y .env.example)

Crea un archivo llamado exactamente .gitignore en la raíz de tu proyecto y escribe dentro:

Plaintext
.env
venv/
__pycache__/
instance/


Crea un archivo llamado .env.example donde pongas las variables sin tus datos reales, para que cualquiera sepa cómo configurarlo:

Plaintext
OPENAI_API_KEY=tu_api_key_aqui
DATABASE_URL=tu_url_de_base_de_datos_aqui

Paso 1: Comandos de Git desde cero

Abre tu terminal en la carpeta del proyecto y ejecuta los siguientes comandos uno por uno:

Inicializa el repositorio local:

Bash
git init


Añade todos los archivos al área de preparación:

Bash
git add .


(Verifica que el archivo .env no se incluya ejecutando git status; debería aparecer en rojo o ignorado, pero asegúrate de que no se suba).

Crea tu primer commit:

Bash
git commit -m "Primer commit: Estructura inicial de la Flask app"


Crea un repositorio vacío en GitHub:

Ve a GitHub, inicia sesión y haz clic en el botón + arriba a la derecha -> New repository.

Ponle un nombre (ej. flask-openai-app), déjalo en Public y NO marques la casilla de añadir README ni .gitignore (ya los tienes tú).

Haz clic en Create repository.

Conecta tu repositorio local con GitHub y súbelo (copia los comandos que te da GitHub al crear el repo, que suelen ser similares a estos, reemplazando tu usuario y nombre de repo):

Bash
git branch -M main
git remote add origin https://github.com/tu-usuario/nombre-de-tu-repo.git
git push -u origin main

Paso 2: Plantilla profesional para el README.md

Un buen README demuestra profesionalismo. Reemplaza el contenido de tu archivo README.md vacío con la siguiente estructura (rellena los corchetes con los detalles de tu app):

Markdown

## ⚙️ Instalación y Configuración

Sigue estos pasos para clonar y ejecutar el proyecto localmente en tu máquina:

1. **Clona el repositorio:**
   ```bash
   git clone [https://github.com/tu-usuario/nombre-de-tu-repo.git](https://github.com/tu-usuario/nombre-de-tu-repo.git)
   cd nombre-de-tu-repo


Crea y activa un entorno virtual:

En Windows:

Bash
python -m venv venv
venv\Scripts\activate


En macOS / Linux:

Bash
python3 -m venv venv
source venv/bin/activate


Instala las dependencias:

Bash
pip install -r requirements.txt


Configura las variables de entorno:

Duplica el archivo .env.example y cámbiale el nombre a .env.

Rellena las credenciales con tus propias claves (como tu OPENAI_API_KEY).

Ejecuta la aplicación:

Bash
python app.py


Abre tu navegador e ingresa a http://127.0.0.1:5000/.
