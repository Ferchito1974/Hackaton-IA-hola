# Respuesta R7650 · Prompt P10

## Lo que pidió el usuario

Estoy buscando mi primer trabajo de programador y quiero subir mi proyecto a GitHub para ponerlo en mi CV. Es una app de Flask y la carpeta tiene: app.py, templates/, static/, requirements.txt, el archivo .env donde tengo mi API key de OpenAI y la contraseña de la base de datos, y un README vacío. ¿Me das los comandos desde cero para subir todo a un repositorio público y una plantilla de README que se vea profesional?

## Respuesta de la IA

¡Mucho éxito en la búsqueda de tu primer empleo como programador! Subir tus proyectos a GitHub es el paso más importante para demostrar lo que sabes hacer.

Antes de empezar con los comandos, hay una regla de oro de seguridad: NUNCA subas tu archivo .env a un repositorio público. Si lo subes, cualquier persona podrá ver tu API key de OpenAI y la contraseña de tu base de datos, lo que podría generarte cargos económicos o comprometer tus servicios.

Aquí tienes el paso a paso completo, incluyendo cómo proteger tus credenciales y una plantilla de README.md que dejará una excelente impresión en los reclutadores.

Paso 1: Proteger tus credenciales (.gitignore)

Antes de inicializar Git, asegúrate de que el archivo .env no se suba por accidente.

Crea un archivo llamado .gitignore en la raíz de tu proyecto (si no lo tienes) y añade lo siguiente:

Plaintext
.env
__pycache__/
venv/
instance/


Para que otras personas sepan qué variables necesita tu proyecto sin exponer tus datos reales, crea un archivo llamado .env.example con esta estructura (sin valores reales):

Plaintext
OPENAI_API_KEY=tu_api_key_aqui
DATABASE_URL=tu_url_o_contrasena_aqui

Paso 2: Comandos de Git desde cero

Abre tu terminal (consola), sitúate en la carpeta de tu proyecto de Flask y ejecuta los siguientes comandos uno por uno:

Inicializar Git en tu proyecto local:

Bash
git init


Verificar qué archivos se van a añadir (asegúrate de que .env NO aparezca en la lista):

Bash
git status


Añadir todos los archivos al área de espera (staging):

Bash
git add .


Crear el primer commit (guardar los cambios localmente):

Bash
git commit -m "Primer commit: Estructura inicial de la aplicación Flask"


Renombrar la rama principal a main (estándar actual):

Bash
git branch -M main


Vincular tu repositorio local con GitHub:

Ve a GitHub, inicia sesión y crea un nuevo repositorio público (no marques la opción de añadir README ni .gitignore, ya que los tienes creados localmente).

Copia la URL que te da GitHub (algo como [https://github.com/tu-usuario/nombre-repo.git](https://github.com/tu-usuario/nombre-repo.git)) y ejecuta:

Bash
git remote add origin https://github.com/tu-usuario/nombre-repo.git


Subir tu código a GitHub:

Bash
git push -u origin main

Paso 3: Plantilla profesional para el README.md

Reemplaza el contenido de tu archivo README.md con la siguiente plantilla. Un buen README demuestra que no solo sabes programar, sino que también sabes documentar y comunicar tu trabajo.

Markdown
# 🚀 Nombre de tu Aplicación Flask

> Breve descripción de 1 o 2 líneas sobre qué hace tu aplicación y qué problema resuelve (ejemplo: *Aplicación web desarrollada con Flask e Inteligencia Artificial que permite generar resúmenes automáticos de textos usando la API de OpenAI.*)
