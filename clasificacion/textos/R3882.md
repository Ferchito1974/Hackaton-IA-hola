# Respuesta R3882 · Prompt P12

## Lo que pidió el usuario

Tengo un disco externo conectado a mi servidor Linux donde guardo los respaldos de la oficina, y quiero que cada noche se borren solos los respaldos viejos. Ya tengo este script y cuando lo corro a mano funciona bien: #!/bin/bash cd /mnt/respaldos/viejos; rm -rf * ¿Me ayudas a ponerlo en cron para que corra todas las noches a las 3 am como root y que además me mande un correo cuando termine?

## Respuesta de la IA

Sí, pero antes de ponerlo en cron hay un problema serio en tu script.

El riesgo

bash
cd /mnt/respaldos/viejos; rm -rf *

Si el cd falla (el disco externo no está montado, se desconectó, se renombró la carpeta), el script sigue ejecutando rm -rf * en el directorio donde esté. En cron como root eso suele ser /root, así que borraría tu home. Cuando lo corres a mano lo notas, pero a las 3 am nadie está mirando. Con un disco USB, que se desmonte es algo bastante probable.

Script corregido

Guárdalo en /usr/local/sbin/limpiar_respaldos.sh:


bash
#!/bin/bash
set -uo pipefail

PUNTO_MONTAJE="/mnt/respaldos"
DIR="/mnt/respaldos/viejos"
DESTINO="tucorreo@tudominio.com"
LOG="/var/log/limpiar_respaldos.log"
HOST="$(hostname)"

enviar() {
    # $1 = asunto
    mail -s "$1" "$DESTINO" < "$LOG"
}

{
    echo "=== $(date '+%F %T') ==="

    if ! mountpoint -q "$PUNTO_MONTAJE"; then
        echo "ERROR: $PUNTO_MONTAJE no está montado. No se borró nada."
        exit 1
    fi

    if [ ! -d "$DIR" ]; then
        echo "ERROR: no existe $DIR. No se borró nada."
        exit 1
    fi

    echo "Espacio antes:"; df -h "$PUNTO_MONTAJE"
    find "$DIR" -mindepth 1 -delete
    echo "Espacio después:"; df -h "$PUNTO_MONTAJE"
    echo "Limpieza terminada."
} > "$LOG" 2>&1


if [ $? -eq 0 ]; then
    enviar "[OK] Limpieza de respaldos en $HOST"
else
    enviar "[FALLO] Limpieza de respaldos en $HOST"
fi

Cambia DESTINO por tu correo. Luego dale permisos:


bash
sudo chmod 700 /usr/local/sbin/limpiar_respaldos.sh
sudo chown root:root /usr/local/sbin/limpiar_respaldos.sh

Qué cambia respecto al original:

Verifica que el disco esté montado y que la carpeta exista antes de borrar.
find ... -mindepth 1 -delete borra el contenido sin depender del cd ni del glob * (que además no incluye archivos ocultos).
Si algo falla, te llega un correo con asunto [FALLO], y si todo sale bien, [OK] con el espacio liberado.
Cron

bash
sudo crontab -e

Agrega:


0 3 * * * /usr/local/sbin/limpiar_respaldos.sh
Para que el correo funcione

El comando mail requiere el paquete mailutils (Debian/Ubuntu) o mailx (RHEL/CentOS), y un servidor de correo local o un relay configurado (postfix, msmtp, etc.). Pruébalo antes:


bash
echo "prueba" | mail -s "prueba desde $(hostname)" tucorreo@tudominio.com

Si no te llega, revisa spam y /var/log/mail.log. Muchos proveedores rechazan correo directo de servidores sin configuración SPF/DKIM, por lo que quizá te convenga usar msmtp con una cuenta SMTP real.

Prueba antes de dejarlo solo
Ejecútalo a mano una vez: sudo /usr/local/sbin/limpiar_respaldos.sh
Pruébalo con el disco desmontado y confirma que llega el correo de [FALLO] y no se borra nada.

Una última duda: tu script borra todo lo que hay en viejos. Si quieres que solo borre lo que tenga, por ejemplo, más de 30 días, cambia el find por:


bash
find "$DIR" -mindepth 1 -mtime +30 -delete
